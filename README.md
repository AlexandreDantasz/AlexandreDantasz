# Olá, eu sou o Alexandre Dantas 👋

Desenvolvedor de software na **Smart Solutions** e estudante de **Ciência da Computação**.
Construo e mantenho sistemas de gestão usados em produção por concessionárias e empresas do
setor automotivo, do banco de dados à integração fiscal.

## O que eu faço

- **ERPs multiempresa (matriz × filiais)**: vendas, ordens de serviço, estoque, financeiro/DRE
  e ponto eletrônico com banco de horas, com isolamento de dados por RLS no PostgreSQL.
- **Integrações fiscais e financeiras**: emissão de NF-e e NFS-e via API (NFE.io), boletos e
  cobrança, com webhooks e edge functions: valor financeiro só é gravado no servidor, nunca no navegador.
- **Back-end .NET**: API e workers de notificação (e-mail/WhatsApp) para agendamento de entrega
  de veículos, com EF Migrations e Docker.
- **Automação interna** em Python/FastAPI para envio de notas e boletos aos clientes.

## Como eu trabalho

- Converso direto com o cliente e transformo a demanda em **escopo fechado com critérios de aceite**.
- Antes de implementar, comparo as alternativas e **explico os trade-offs** para a decisão ser tomada junto.
- Uso **IA no desenvolvimento**, mas tudo passa por revisão de código antes de ir para produção.
- **Cada bug encontrado vira teste de regressão.**
- Gosto de **maratonas de programação**: é onde treino algoritmos e raciocínio sob pressão.
